# Contributing to the Sleep Disorder Stacking Benchmark

Thank you for your interest in contributing to this research repository!

## Code of Conduct
We are committed to providing a welcoming and inclusive environment for everyone. Please be respectful and constructive in all interactions.

## Submitting Pull Requests
1. **Fork the Repository**: Create your own fork and create a branch from `main`.
2. **Set up Environment**: Install dependencies using `pip install -r requirements.txt`.
3. **Reproducibility Guarantee**:
   - Any code modifications must preserve deterministic reproducibility.
   - Do not commit modified versions of the dataset or large temporary artifacts.
4. **Code Quality**:
   - Ensure scripts follow standard Python conventions and maintain documentation.
   - Run `python -m py_compile reproducibility_package/code/*.py` to ensure clean syntax.
5. **Open a PR**: Submit your pull request with a detailed summary of changes and validation results.

## Reporting Issues & Questions
If you identify any discrepancies or have questions regarding the statistical analyses, please open an issue with:
- A clear description of the query or discrepancy.
- The relevant script name and line numbers.
- Any environment specifications or log outputs.
